# Prompt Templates

Copy a template and replace each `<...>`. The skill answers in the language you write in.

## Quick overview of a field
```
Quick overview: scan the literature on <research topic>.
Tell me the main directions, how the focus has shifted in recent years and the main debates,
then suggest a few anchors worth tracing in depth.
```

## Standard review
```
Do a literature review on <research topic>.
My data / setting: <brief description>. I care most about <a question or a limitation of current practice>.
```

## Trace how a method or theory evolved
```
Trace mode: which later works genuinely changed the assumptions of <method / theory / paper>?
For each step, explain the assumption changed, the mechanism, the price paid, and when it is better.
```

## Check whether other fields do it better
```
My field (<field>) commonly uses <approach>. Abstract it into a domain-free problem,
find the frontier for that problem in other disciplines, and assess whether it can transfer back and what adaptation it would need.
```

## Related-work section
```
My work <one sentence: what it does and which prior assumption it changes>.
Map the landscape and lineage of <related area>, and show where my work sits and which limitation it addresses.
```

## Research gaps
```
Deep review: <research topic>. Focus on which assumptions every current frontier approach still shares,
and which problems are solved in other disciplines but not yet applied here.
Rank the opportunities by value and risk for my project (<brief description>).
```

## 中文示例
```
帮我做一个关于 <研究主题> 的文献综述。
我的数据/场景是 <简述>，最关心 <某个问题或局限>。
```
